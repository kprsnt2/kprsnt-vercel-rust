POST /api/interview

Formal interview agent for HR and recruiter screening. Handles salary, experience, and technical depth. Can auto-send email replies.

RAG Email Formal
Request Body
{
  "message": string (required),
  "from_email": string (required for email),
  "subject":  string (optional),
  "send_email": boolean (default: true)
}
cURL Example
curl -X POST https://kprsnt.in/api/interview \
  -H "Content-Type: application/json" \
  -d '{"message": "Tell me about your AI experience",
       "send_email": false}'
