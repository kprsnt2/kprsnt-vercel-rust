How Agents Use Custom Skills

Each autonomous agent in AI Eco has a distinct role and executes via specialized custom skills.

Skill: Git Ingestion
1. GitHub Scout Agent

Monitors user commit activity across all repositories via GitHub Events API. Uses custom commit head SHA resolution to harvest commit messages and publishes authentic dev logs into AI_Eco_Blogs/.

Custom Skill: Commit Harvester & LLM Synthesis
Skill: Market Intelligence
2. Dashboard Agent

Calculates telemetry metrics (real commits, language distributions, active automations) and utilizes LLMs to dynamically estimate US market salary benchmarks based on active tech stack shifts.

Custom Skill: Telemetry & Compensation Analyzer
Skill: Schema Alignment
3. Portfolio Sync Agent

Continuously validates and synchronizes Python knowledge base constants, role-tailored resume configurations, and project showcases across frontend views.

Custom Skill: Multi-Role KB Synchronizer
Skill: Protocol Interface
4. MCP Engineer Agent

Exposes the ecosystem's internal telemetry, portfolio capabilities, and project facts as standard FastMCP tools so external AI assistants (like Claude) can query live metrics directly.

Custom Skill: FastMCP Server Architecture
Skill: Context Engineering
5. Docs Agent

Maintains internal skill guides, prompt instructions, and interactive API documentation to keep the RAG chatbot context embeddings aligned with newly shipped capabilities.

Custom Skill: Knowledge Grounding & Docs
Skill: Architectural Vis
6. Readme Agent

Generates clean architectural summaries, flowcharts, and key project callouts directly into the project's root README.md, ensuring the public repo matches live deployments.

Custom Skill: Mermaid Diagram Synthesizer
