RashBot — AI Chat Widget

A floating chat widget on every page. Ask it anything about Prashanth's work, projects, or skills.

RAG Dynamically loads resume.json as context for every query
Memory Maintains the last 8 conversation turns for follow-up questions
Tools Can execute functions — e.g., "Send me your resume" triggers an actual email via Resend
Model Gemini 2.5 Flash with automatic function calling enabled

/api/chat_agent

POST

Casual conversational AI — the same engine behind RashBot. Supports function calling.

Request
{
  "message": string (required),
  "history":  [{"role": "user", "content": "..."}],
  "send_email": boolean (default: false)
}
cURL
curl -X POST https://kprsnt.in/api/chat_agent \
  -H "Content-Type: application/json" \
  -d '{"message": "What projects has Prashanth built?"}'
